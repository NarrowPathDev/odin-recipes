# Odin Recipes

This project is part of The Odin Project Foundations course. The goal is to build a basic recipe website using HTML and practice the fundamentals I have learned so far.

The website includes a main page that links to multiple recipe pages. Each recipe page contains an image, description, ingredients list, cooking steps, and a link back to the home page.

## Skills Demonstrated

By completing this project, I will demonstrate my ability to:

- Create and structure HTML documents
- Use headings, paragraphs, links, and images
- Create ordered and unordered lists
- Link multiple HTML pages together
- Organize files and directories within a web project
- Use Git and GitHub to track and publish my work

This project is focused on building a strong HTML foundation before moving on to CSS and more advanced web development concepts.
